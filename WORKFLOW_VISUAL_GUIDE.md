## ⚡ Quick Reference

### Can I...?

| Action | Requirement | Validation Function |
|--------|------------|---------------------|
| Submit event to KKF | Event has sponsors | `canSubmitEventToKKF()` |
| Create match | Event submitted to KKF | `canCreateMatchForEvent()` |
| Assign match | Both clubs confirmed | `canAssignMatchToEvent()` |
| KKF approve match | Match assigned to event | `canKKFApproveMatch()` ⭐ |
| Conduct weigh-in | Match KKF approved | `canConductWeighIn()` |
| Start match | Weigh-in complete | `canStartMatch()` |
| Record results | Match in progress | `canRecordResults()` |
| Complete match | Results recorded | `canCompleteMatch()` |
| Close event | All matches complete | `canCloseEvent()` |

## 🆕 What's New in v2.0?

### Step 6: KKF Match Approval (NEW!)

**Before v2.0:**
```
Assigned to Event → Weigh-In Complete
```

**After v2.0:**
```
Assigned to Event → KKF Approved → Weigh-In Complete
                         ⭐ NEW STEP
```

**Why this change?**
- KKF needs to review each match individually for safety
- Separates event approval from match approval
- Allows KKF to reject specific matches without rejecting entire event
- Better aligns with real-world federation processes
