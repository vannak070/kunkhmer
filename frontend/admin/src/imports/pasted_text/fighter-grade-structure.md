🥊 1. Purpose of Fighter Grade

Fighter Grade = skill level classification

👉 Helps:

Match fair opponents

Organize better events

Control progression (amateur → pro)

⚙️ 3. How Grade is Calculated (System Logic)
Basic Logic (Start Simple)

Grade is based on:

Number of fights

Win rate

KO rate

Example:

D → C

≥ 3 fights

C → B

Win rate ≥ 50%

B → A

Win rate ≥ 65%

≥ 5 fights

A → S

Win rate ≥ 80%

KO or title wins

🔥 Advanced Logic (Later Phase)

Add:

Opponent strength

Win streak

Recent performance

👉 More accurate ranking

🧩 4. Where to Use Fighter Grade in System
🥊 Match Creation (VERY IMPORTANT)

Only allow:

Same grade

Or ±1 grade difference

👉 Prevent mismatch fights

🏟 Event Organization

Main event → Grade A / S

Undercard → Grade B / C

📊 Ranking System

Separate leaderboard by grade

Or use grade as ranking layer

👤 Fighter Profile UI

Show:

Grade badge (big visual)

Color coding:

D = Gray

C = Blue

B = Green

A = Gold

S = Red / Champion
