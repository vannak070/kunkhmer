KKF Batch Create – Function List (No Excel)
1. Batch Create Entry Functions
* Create Batch Matches Button
* Open Batch Create Modal/Page
* Auto-link to Event
* Choose Input Method
    * Manual Table Input
    * Template-Based Creation

2. Manual Batch Input Functions
* Dynamic Match Row Creation (Add/Delete Row)
* Auto Match Number Generation
* Fighter Selection (Dropdown + Search)
* Weight Class Selection
* Match Type Selection
* Rounds Input
* Glove Size Selection
* Champion Toggle (Title Fight Yes/No)
* Duplicate Row Function
* Bulk Edit (Apply value to all rows)
* Quick Fill (Auto-fill repeated values like rounds/gloves)

3. Template-Based Creation Functions
* Select Match Template
    * Example: Standard Event (10 matches)
    * Example: Championship Event
    * Example: Weekly Fight
* Auto Generate Match Rows
* Edit Generated Matches
* Save as Custom Template (Optional)

4. Validation Functions
Fighter Validation
* Check Fighter Active Status
* Check Weight Class Matching
* Check Medical Clearance
* Check Suspension / Ban Status
Match Validation
* Prevent Duplicate Fighter in Same Event
* Validate Gloves by Weight Class
* Validate Match Type Rules
* Validate Champion Eligibility

5. Champion Functions (Within Batch)
* Enable Title Fight Toggle
* Select Championship Title
* Auto Suggest Current Champion
* Validate Title Fight Rules
* Prepare Champion Update After Result

6. Batch Processing Functions
* Save Batch as Draft
* Auto Save Draft (optional)
* Edit Batch Before Submission
* Delete Batch
* Submit Batch to KKF

7. Approval Functions (KKF Admin)
* View All Matches in Batch
* Approve All Matches
* Approve Individual Matches
* Reject Matches (with reason)
* Bulk Approval / Rejection
* Assign Referees & Judges

8. Status Management Functions
Batch Level
* Draft
* Submitted
* Partially Approved
* Fully Approved
Match Level
* Draft
* Pending Approval
* Approved
* Rejected
* Completed

9. Notification Functions
* Notify Organizer on Submission
* Notify KKF Admin for Review
* Notify Fighters After Approval
* Notify Officials Assignment
* Notify Rejection with Reason

10. UI/UX Supporting Functions
* Inline Editing (fast input, no popup)
* Color Validation Indicators
    * Red = Error
    * Yellow = Warning
    * Green = Valid
* Sticky Table Header
* Scrollable Table (for many matches)
* Search Fighters Quickly
* Drag & Drop Match Order
* Row Highlight for Errors

11. Advanced Functions (Optional)
* Auto Match Generator (based on ranking)
* Conflict Detection (fighter double booking)
* Smart Suggestions (balanced fights)
* Real-time Sync with Fighter Records
