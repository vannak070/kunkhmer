1️⃣ Broadcast Station Management

Purpose: Manage TV/Online channels broadcasting events.

Fields / Attributes:

Station Name (Khmer & English)

Station Type (TV / Online / Streaming Platform)

Country / Region

Contact Person (Name, Phone, Email)

Contract / License Number

Broadcast Rights Start & End Date

Logo / Media Upload

Status: Active / Inactive

System Rules:

Prevent duplicate station entries

Auto-link station to events (when broadcasting)

Track broadcast history per event

Notifications when broadcast contract is about to expire

UI/UX Suggestions:

Station Card: Name, Type, Status, Next Event Broadcast

Broadcast Assignment Modal: Select station per event

Dashboard Widget: Upcoming events per station

2️⃣ Sponsor Management

Purpose: Manage sponsors supporting events, clubs, or fighters.

Fields / Attributes:

Sponsor Name (Khmer & English)

Sponsor Type (Corporate / Individual / Brand)

Contact Person (Name, Phone, Email)

Sponsorship Contract Number

Sponsorship Start & End Date

Assigned Event / Fighter / Club

Logo / Media Upload

Status: Active / Inactive

System Rules:

Prevent duplicate sponsor entries

Auto-link sponsor to assigned event/fighter/club

Track sponsorship history and expiry

Notifications for contract renewals or expirations

UI/UX Suggestions:

Sponsor Card: Name, Type, Status, Assigned Event

Sponsor Assignment Modal: Link sponsor to event, fighter, or club

Dashboard Widget: Active Sponsors & Upcoming Renewal Dates

3️⃣ Recommended Missing Functions

These are optional but highly valuable for management and system flexibility:

A. System Configuration

Set rules for fighter eligibility (age, rest period, medical validity)

Configure event approval workflow

Configure notifications (channels, frequency, escalation)

Define default fighter grades and club types

B. Role & Permission Management

Add / Remove User Roles: Federation Admin, Promoter, Organizer, Club Manager

Assign permissions per module (Fighter, Event, Match, Club, Notification)

C. Event Template Management

Create event templates (Main Event, Co-Main, Undercard)

Pre-fill fight slots, venue info, expected fighters

Save and re-use templates for faster event creation

D. Notification Preferences

Global settings: push / email / SMS

User-specific overrides

Define trigger events for each notification type
